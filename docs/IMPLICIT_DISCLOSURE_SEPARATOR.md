# Implicit fixed-support disclosure separation

Implementation checkpoint: 2026-09-05. The implementation is
`ordered_run_disclosure_separator.py`; it does not change the frozen city runs
or the existing support-maximization branch-and-price implementation.

## Model and pricing

Sort public rows by their declared index. The API uses positions in that sorted
array, not input-list order, as fact keys. Every event column R contains at least
two rows and at least one core, is connected by strict positive overlap, and
has simultaneous occupancy at most C. Optional rows have usage at most one;
each core has usage exactly one. The declared support count q is fixed.

The separator minimizes the additive target

    H(x) = sum_R (kappa + sum_{i in R} w_i) x_R
    subject to core cover = 1, buffer usage <= 1,
               sum_R |R intersect buffers| x_R = q,
               disclosed usage and pair facts,
               x_R in {0,1}.

This covers selected-member sums/means at fixed q and event count. It does not
implement arbitrary within-event nonlinear functions, unknown q, uncertain
timestamps, noisy answers, or an adaptive acquisition policy.

At a branch node, mandatory cores and positively fixed buffers have equality
duals pi; free optional buffers have nonpositive inequality duals nu; the fixed
support equality has free dual sigma. Reduced cost is

    kappa + sum_{i in R} [w_i - pi_i - sigma * 1{i is a buffer}].

Thus fixed support shifts every buffer's pricing weight by sigma. The per-event
cost is a constant offset. The existing forced-in/forced-out Ryan--Foster cases
and fixed-span interval LP are still applicable. No support-cardinality row is
added to the local interval LP; doing so would require a new integrality proof.
All columns are generated by pair seeds and pricing, not full event enumeration.

A positive co-membership answer must do TWO things: impose columnwise together
and force both optional endpoints to be used. Together alone permits both rows
to be absent. A negative answer forbids joint membership but need not force
usage of either endpoint. Tests cover both semantics.

## Valid bounds, including interrupted nodes

Let d be the value of any master dual vector with nonpositive inequality
multipliers, and let rho be a lower bound on the reduced cost of every legal
event column. Since every event covers at least one core and each core is
covered once, every feasible master satisfies sum_R x_R <= number_of_cores.
Consequently

    H(x) >= d + number_of_cores * min(0, rho).

This is an objective lower bound even when pricing has small numerical
residuals; it does not equate the restricted-master objective with a full-master
bound. During phase one the same inequality applied to zero physical column
cost proves original infeasibility if its right-hand side is strictly positive.

Each fixed-span LP maximizes w'x under A x <= b and finite integer bounds l,u.
For ANY nonnegative multiplier lambda, a valid upper bound is

    b'lambda + sum_j max(l_j r_j, u_j r_j),
    where r = w - A'lambda.

The implementation obtains proposed multipliers from HiGHS, projects signs,
and evaluates this expression in rational arithmetic. Variable-bound residuals
are included explicitly. LP infeasibility is accepted only after an exact box
precheck or a slack-relaxation multiplier gives a negative bound for the
identically zero objective (a contradiction for every feasible point).

Costs are the exact rational values of the supplied Python floats/Fractions;
this does not assert that measured real-world quantities are exact. Witness
connectivity, capacity, usage, support, pair facts, and objective are replayed.
A restricted MILP supplies only a feasible incumbent, never an absence proof.

Nodes removed due to an absolute optimality tolerance keep their repaired
bounds. A node popped before timeout/pricing failure keeps its inherited bound.
The final bound takes all such nodes into account. A nonzero gap is never
rounded to zero for a threshold comparison.

## Decision interface

The target label is exactly `H >= threshold`, with no tolerance shift. For a
positive reference label the separator minimizes H; absence requires the global
lower bound to be at least the threshold. For a negative reference label it
minimizes -H; absence requires the resulting global upper bound on H to be
strictly below the threshold. A feasible opposite-label witness can be returned
without endpoint closure. If neither condition is proved, return UNRESOLVED.

A reference world is replayed before separation and provides truthful answers;
it is not silently used as a column library. Infeasibility despite that valid
reference is an inconsistency, not a vacuous certificate.

## Certificate master and optimality

For each opposite world W, the disagreement set D(W) contains allowed facts on
which W differs from the reference. Any valid certificate must hit D(W). The
master solves the accumulated unit-cost hitting set by exact finite search.
The implicit separator either supplies another cut or proves absence of all
opposite worlds. At termination, the master objective is a lower bound on every
valid certificate and its proposed certificate is feasible, so it is minimum.
If either stage is unresolved, minimum-certificate status is withheld.

This is a curator/ex-post certificate: the reference world is known to the
curator. Certificate size is not the query count of an uninformed adaptive
policy. Known usage/pair facts are conditioned on and excluded from the cost.

## Validation and limitations

`test_ordered_run_disclosure_separator.py` independently enumerates small worlds,
tests actual branching on a fractional master, forbids full-column construction
inside the solver, and injects interruptions and near-threshold counterexamples.
`selective_disclosure_branch_price_audit.py` compares complete minimum
certificates with the previous explicit oracle and runs constructed simultaneous
and sequential-turnover stress cells. Raw witnesses are not serialized.

The identical-interval stress uses a deterministic feasible clique-packing
warm start that does not inspect the reference world. Closure still requires a
valid bound. These easy special cases do not establish general 32-row or
operational city-scale performance. Sequential stress has separate statuses.
Frozen NYC/Chicago counts remain unchanged.

## Scope correction for the all-partitions formula audit

The older all-partitions model allows singleton blocks; the physical event
model does not allow singleton events. It is not directly the family of n
identical cores at capacity n. A faithful conditional embedding uses n known
two-row buddy bundles: 2n identical mandatory intervals, capacity 2n, and the n
within-bundle together facts given as prior information. The formulas count
additional cross-bundle facts. The old enumeration uses one balanced truth
partition per K, not every possible truth block-size profile.
