\section{Integer branch-and-price details}
\label{app:integer-bp}

Let $\mathcal C$ be the finite family of feasible run-member masks.  The master
selects nonnegative column weights $\lambda_R$, covers each core exactly once,
and uses each optional buffer at most once.  At a branch node, some buffer
usages are fixed to zero or one and some row pairs are constrained to occur
together or separately.

\subsection{Proof of Theorem~\ref{thm:bp}}

At every node, column generation terminates with the exact node LP bound because
$\mathcal C$ is finite and the pricing oracle returns a most improving
admissible column, or certifies that none exists.  A fractional buffer usage
$u_i\in(0,1)$ is separated by the exhaustive disjunction $u_i=0$ versus
$u_i=1$.  If all usages are integral but the master solution is not an integer
partition, consider two positive-weight partitions in its convex support.  They
cannot induce the same co-membership indicator for every row pair unless they
have the same equivalence classes and hence the same run-member masks.  Thus
some pair has fractional co-membership $z_{ij}\in(0,1)$.  Ryan--Foster
branching separates the parent solutions into $z_{ij}=1$ (together) and
$z_{ij}=0$ (separate).

Every child therefore contains a subset of the parent integer worlds, and the
two children cover all of them.  Along a root-to-leaf path, each effective
branch fixes a previously fractional usage or pair relation.  There are
finitely many buffers, pairs, and run masks, so no infinite path exists.  A
leaf with an integral master solution supplies a feasible incumbent; a leaf
whose exact LP bound does not improve the incumbent is safely pruned.  When the
queue is empty, the incumbent matches the best valid upper bound and is the
global integer optimum.  If no incumbent exists, infeasibility is certified.

\subsection{Branch-compatible pricing}

For a fixed root and temporal span, a together decision on $(i,j)$ is the union
of two cases: both rows are forced in or both are forced out.  A separate
decision is the union of the cases $i$ out or $j$ out.  Logical propagation
removes inconsistent or redundant cases.  In each surviving case, forced-in
rows are unit equalities and forced-out rows receive zero upper bounds.  The
remaining segment-coverage, boundary-bridge, and occupancy rows retain the
consecutive-ones order, so the pricing LP returns an integral run column.
The case count may be exponential in branch depth, which is why the result is
an exact medium-instance method rather than a polynomial bound for the full
master.

\subsection{Locked nonintegral witness}

The artifact includes a finite run family whose root relaxation has value four
while every integer partition has value three.  The verifier checks column
feasibility, row coverage, optional-row usage, the reported incumbent, and the
closed branch queue independently.  The branch-and-price implementation closes
this witness in 17 nodes.  On the public NYC audit cohort, an independently
enumerated finite family with 54, 394, and 1,719 columns at capacities two,
three, and four verifies the branch-and-price optima reported in
Table~\ref{tab:bp}.

\section{Controlled-truth protocol}
\label{app:truth}

Each generated instance contains three core rows, eight candidate buffers, and
a latent ordered partition.  Every core receives one direct member; one or two
additional members connect sequentially through the direct member, while
remaining rows are temporally plausible distractors.  Public outcomes are not
used in candidate ranking.  At $C=4$, the temporal generator is the same as at
$C=3$ and the generated truth has peak occupancy at most two; the $C=4$ cell
therefore studies the larger admissible decomposition set rather than a new
high-occupancy data-generating process.

The full-universe coverage check requires both that the true selected-member
mask is reachable by the exact master and that its scalar aggregate lies in the
reported endpoint pair.  For threshold decisions, we use three fixed cutoffs
$0.25$, $0.50$, and $0.75$.  A frontier identifies the positive decision when
its lower endpoint exceeds the threshold, identifies the negative decision when
its upper endpoint is below the threshold, and otherwise abstains.  A point
error at an identified threshold would contradict feasibility and is treated as
an audit failure.

Candidate truncation retains the top four, six, or eight buffers under the
outcome-blind temporal score.  We report member recall, exact representability
of the full true world, availability of a frontier at the true support count,
and scalar coverage.  These quantities are intentionally distinct: a scalar
can fall inside a misspecified interval by coincidence even when the true
relational world is absent.
