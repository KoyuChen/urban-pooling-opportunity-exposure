# Archive

This directory preserves superseded research material without keeping it in the
active paper, code, or workflow surface.

- `pre-eventfrontier-2026-09-04/` contains the last root documentation, paper
  fragments, compiled draft, and access-blocker note from before repository
  convergence on EventFrontier.
- `legacy-ai4science/` contains the weak-node-score and early hidden-matching
  pilot, including its model, integration runs, reports, and manifest builder.
- `workflows/` contains exact historical GitHub Actions definitions renamed
  with `.disabled` suffixes so frozen one-off panels do not execute.

Archived material is provenance only. It is not imported by current CI, is not
the current manuscript source, and must not be cited as current evidence.
