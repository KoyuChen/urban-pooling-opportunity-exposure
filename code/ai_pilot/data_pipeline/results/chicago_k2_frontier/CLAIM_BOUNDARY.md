# Claim boundary

## Supported

For the adaptively selected released 15-minute core, the extraction is
metadata/count stable and count-closed over every literal public
`Shared Trip Match=true, Trips Pooled=2` row that can be incident to a core
trip under the declared nearest-15-minute release model. The result is a
boundary-complete public temporal candidate superset for core-incident edges.

The radius and Gamma families are nested. Eight of ten complete curve/query
chains, covering four of five query families, have paired optimal numerical
endpoints and pass the widening audit with zero mathematical violations.

## Not supported

Chicago does not release Shared Trip ID or co-rider identity in these rows.
The analysis therefore does not establish actual hidden-run closure, identify
true partners, recursively close buffer-row runs, estimate partner recall,
validate Chicago conformal coverage, or establish a city-population effect.
Released distance, duration, fare, centroid, and area fields are not latent
exact trip attributes.

The 2 km radius is an analyst sensitivity screen, not a proven necessary
support rule. Gamma counts measured out-of-radius core incidences only;
unmeasured-distance edges are retained with zero Gamma cost.
