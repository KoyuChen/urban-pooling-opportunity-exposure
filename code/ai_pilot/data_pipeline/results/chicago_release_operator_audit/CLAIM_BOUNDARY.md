# Claim boundary

## Supported

For the fixed released 15-minute core, the live extraction is snapshot-relative
and server-count closed for both the 611 literal public K=2 temporal candidates
and the 50,405 public trips contributing to their released endpoint bins.

The closed outer released-time-envelope graph has 24,274 intersections. After
separating 5,812 boundary-touch-only intersections, the positive-length outer-
envelope graph retains 18,462 edges and has an optimal core cover. Conditional
on that graph, two certified core covers exist; the displayed pair differs on
all 60 core assignments. This is graph-cover multiplicity, not two complete
hidden Chicago worlds. It neither establishes actual trip overlap nor certifies
hidden-partner nonidentification.

Within the same graph-cover feasible set, the sharp spatially unmeasured
core-incidence range is `[15,60]`. The release operator licenses no additional
necessary deletion among spatially unmeasured edges.

Separately, an abstract four-row construction shows that the documented public-
field map does not encode Shared Trip ID. It does not apply to this cohort, is
not linked to the displayed covers, and does not validate the City's private
implementation.

The candidate endpoint-mask equality is exact for this 611-row snapshot subset
only. Contributor rows contain counterexamples, so no Chicago release rule is
inferred from that equality.

## Not supported

The audit does not validate the City's private production code, identify the
cause of a public blank, reconstruct latent tract cells, authenticate a blank-
to-LOW converse, establish actual positive-duration overlap, construct common
exact-timestamp witnesses or vehicle/provider-consistent runs, complete the
remaining buffer-row K=2 pairing, identify or prove nonidentification of hidden
partners, measure partner recall, recursively close buffer runs, or turn a
centroid radius into a necessary spatial compatibility rule.

Every public blank uses an uninformative TRUE release clause unless independent
operator evidence is supplied. This run emits zero LOW literals and leaves
`city_implementation_validated=false`.
