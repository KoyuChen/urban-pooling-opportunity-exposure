\title{EventFrontier: Aggregate Identification over Hidden Temporal-Event Partitions}
\begin{document}
\begin{abstract}
Public event logs can disclose every participation while suppressing the key
that groups rows into events. Temporal events impose a distinct feasible-world
object: one joint timestamp completion, positive-overlap connectivity, and
instantaneous capacity. Its uncertainty has three layers---event partitions,
selected-row projections, and additive frontiers---that need not change
together. \methodname{} bounds aggregates over this object. For nested fixed-$q$
models, one frontier agrees exactly when the restricted projection reaches both
exposed endpoint faces; all selected-row additive frontiers agree exactly when
the binary projections agree. For exact intervals, an integral LP prices one
fixed-root, fixed-span event inside branch-and-price; uncertain time retains
explicit feasibility and unresolved statuses. Candidate truncation creates
false certificates in 6.9--7.7\% of apparently certified controlled decisions.
An annotated transfer retains 81/82 follow-up worlds but certifies only 29/246
decisions. Chicago completes 90/96 windows and closes 10,728/10,762
data-complete endpoint pairs; 34 remain unresolved. NYC yields 125/126
witness-certified ambiguous cells. In non-clique views, 36/48 restrictions add
only partitions and 4/48 also add projections, but no addition reaches a
declared endpoint. This is a mechanism result, not model equivalence or an
ordered-event advantage.
\end{abstract}
